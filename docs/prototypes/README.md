# 墨语博客平台原型图

本目录包含基于当前 Vue 3 博客项目页面结构与功能实现生成的高保真桌面端原型图。全部图片使用 ImageGen 内置模式生成，统一采用内容优先的浅色设计系统：暖灰背景、白色内容层、靛蓝主色、克制阴影与清晰状态色。

## 原型清单

1. `01-discovery-home.png`：发现首页。重组搜索、推荐、标签、文章流与侧栏，减少重复筛选。
2. `02-article-detail.png`：文章详情。增加阅读进度、悬浮互动、目录、作者信息和评论输入。
3. `03-article-editor.png`：文章编辑器。增加文章大纲、自动保存、编辑/预览模式、发布设置和发布前检查。
4. `04-ai-writing-assistant.png`：AI 写作助手。把通用聊天转为关联文章上下文的写作工作流，支持引用和插入草稿。
5. `05-community-square.png`：社区广场。以提问、经验分享和投票为核心，区别于文章发现信息流。
6. `06-creator-workspace.png`：创作者工作台。整合公开主页、文章状态、草稿进度、创作数据和分类管理。
7. `07-admin-dashboard.png`：管理后台。以审核、举报、风险和运营趋势为核心，替代装饰性欢迎区。
8. `08-auth-entry.png`：登录/注册入口。统一品牌首屏、表单状态、邮箱验证码登录和协议入口。

## 主要问题与设计响应

- 中文文案：当前部分源文件存在乱码文本，原型统一使用正确中文标签。
- 导航结构：`Community.vue` 已存在但未注册到当前路由；原型把“社区”提升为一级入口，并明确其互动定位。
- 首页信息架构：当前标签筛选在主区域和侧栏存在重复，原型让侧栏承担精选、趋势和创作数据。
- 阅读体验：详情页缺少目录、阅读进度、收藏分享和评论的集中入口，原型将其整合为三栏阅读布局。
- 创作流程：当前编辑器缺少自动保存反馈、预览切换、可见性、SEO 和发布检查，原型补全发布闭环。
- AI 能力：当前 AI 页面以模型和对话为中心，原型改为文章上下文、快捷能力和插入草稿的场景化助手。
- 个人空间：当前个人主页和文章管理较割裂，原型合并为创作者工作台。
- 后台首页：当前快速入口多、操作队列少，原型优先展示待审核、举报、风险和近期动态。

## ImageGen 提示词集合

所有提示词均使用 `ui-mockup` 类型，并共享以下约束：1440px 桌面端、高保真产品界面、无浏览器外框、无设备模型、中文清晰可读、可访问性对比度、轻边框与克制阴影、避免玻璃拟态和过量渐变。

- 发现页：全局导航、搜索、推荐/最新/热门、主题标签、三张文章卡、精选/热门标签/创作数据侧栏。
- 文章详情：左侧互动、中央长文、右侧目录与作者卡、底部评论输入。
- 编辑器：文章大纲、Markdown 工具栏、自动保存、三种预览模式、发布检查与设置侧栏。
- AI 助手：历史会话、结构化回答、引用来源、文章上下文、快捷能力和插入草稿。
- 社区：讨论发布器、关注/推荐/最新、问答/分享/投票内容、话题与关注建议。
- 创作者工作台：资料横幅、内容指标、文章状态筛选、草稿完成度、趋势与分类。
- 管理后台：侧边导航、运营指标、趋势图、今日待办、审核表、风险分布与动态。
- 登录入口：品牌插画、登录/注册标签、表单验证、验证码登录、协议与隐私入口。
